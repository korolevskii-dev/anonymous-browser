# AnonymousFox Browser

AnonymousFox Browser is a privacy-focused browser based on Firefox, built for users who want stronger online privacy, encrypted traffic routing, proxy support, and flexible search engine selection in one place.

## Overview

AnonymousFox Browser combines the stability of Firefox with a hardened privacy-oriented browsing experience.  
It is designed for users who want more control over how their traffic is routed, how search requests are handled, and how browser tracking can be reduced during daily use.

The browser includes:

- Proxy connection support
- Encrypted traffic routing inspired by onion-style privacy models
- Privacy-focused browser hardening
- Built-in search engine selection
- Reduced tracking and fingerprinting exposure

## Features

### Privacy-focused browsing
AnonymousFox Browser is configured to help reduce data leakage and improve privacy by limiting trackers, isolating sessions, and reducing unnecessary background communication.

### Proxy support
The browser can connect through custom proxy servers, including:

- HTTP / HTTPS proxies
- SOCKS5 proxies
- Authenticated proxies
- Region-based proxy routing

This helps users separate their browsing identity from their direct network connection.

### Layered encryption model
AnonymousFox Browser supports encrypted routing concepts inspired by onion-style privacy systems.  
Depending on the implementation, traffic may pass through multiple encrypted layers before reaching its destination.

Important:
AnonymousFox Browser is **not Tor Browser** and is **not affiliated with the Tor Project** unless explicitly stated by the developers.  
If Tor-level anonymity is claimed, the underlying network must actually provide multi-hop anonymized routing and metadata protection.

### Search engine selection
Users can choose a preferred search engine directly in the browser settings.

Supported search engines include:

- DuckDuckGo
- Bing
- Startpage

This allows users to choose between privacy-oriented search and broader mainstream indexing.

### Hardened privacy defaults
AnonymousFox Browser can include privacy-enhancing defaults such as:

- WebRTC leak reduction
- DNS prefetch disabling
- Telemetry disabling
- Fingerprinting resistance
- Third-party cookie blocking
- Tracking script isolation

### Familiar Firefox-based experience
The browser preserves a familiar Firefox-style workflow while adding stronger privacy controls and anonymity-oriented options.

## Search engine support

AnonymousFox Browser offers several built-in search providers.

### DuckDuckGo
A privacy-oriented search engine that avoids building detailed personal search profiles.

### Bing
A mainstream search engine with broad indexing and general-purpose results.

### Startpage
A privacy-focused search engine that helps users obtain search results with reduced direct data exposure.

## Security and anonymity

AnonymousFox Browser is designed to improve privacy, but anonymity depends on both browser configuration and the actual network architecture.

True anonymity requires more than a simple proxy. It may depend on:

- Multi-hop routing
- Strong encryption between nodes
- IP isolation
- DNS leak protection
- WebRTC leak protection
- Fingerprint reduction
- Cookie and session isolation

No browser can guarantee complete anonymity without a properly designed routing system and safe user behavior.

## Installation

1. Download the latest AnonymousFox Browser release.
2. Install the browser on your system.
3. Launch the browser.
4. Open the network settings panel.
5. Configure your proxy if needed.
6. Select your default search engine.
7. Apply the recommended privacy settings.

## Configuration

AnonymousFox Browser allows users to customize settings such as:

- Proxy type
- Proxy host and port
- Authentication credentials
- Default search engine
- DNS behavior
- Privacy protection level
- Session isolation behavior

## Recommended setup

For stronger privacy, it is recommended to:

- Use a trusted SOCKS5 proxy or privacy routing layer
- Keep the browser updated
- Avoid mixing anonymous sessions with personal accounts
- Disable unnecessary extensions
- Use separate profiles for personal and private browsing

## Limitations

AnonymousFox Browser improves privacy, but it does not automatically provide perfect anonymity.

Limitations may include:

- Browser fingerprinting risks
- Proxy trust issues
- Traffic correlation risks
- Unsafe browsing habits
- Third-party extension vulnerabilities
